# Game Concept Architect

一句话游戏创意 → 可验证概念蓝图。

来源: ParanoiaSkills v0.8.0 (MIT) - https://github.com/DY-2026/ParanoiaSkills

## 9步强制顺序

1. Concept Seed Extraction — 提取玩法核心假设
2. Player Verbs — 玩家反复做什么
3. Action-Goal Alignment — 动作与目标对齐
4. Player Promise Contract — 游戏的玩家承诺
5. Core Loop Design — 行动→选择→风险→反馈→奖励
6. Uncertainty Calibration — 不确定性来源和设计影响
7. System Dynamics Check — 系统组合后的动态和阶段
8. Production Feasibility — 团队能力范围内的可行性
9. Scope Gate — MVP/Vertical Slice/Demo/Release/Cut
10. Validation Plan — 最小原型、测试目标、通过/失败标准
